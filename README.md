es una aplicacion web sencilla tipo CRUD para gestionar contactos, permite crear, ver, editar y eliminar registros y fue desarrollada guiandome de prompts de inteligencia artificial.
Tecnologias utilizadas:
HTML para la estructura
CSS para el diseño 
JavaScript para la logica
para guardar los datos use el localstorage asi que no necesito base de datos
como asistente de IA use Claude
instrucciones para ejecutarlo. Son muy simples, se descarga el repositorio, se abre la carpeta y se hace doble clic en index.html. Se abre en el navegador y funciona de inmediato, sin instalar nada.
Lista de Prompts:
Crea una app web CRUD de contactos con HTML, CSS y JavaScript puro. Debe guardar los datos en localStorage. Dame index.html, style.css y app.js
